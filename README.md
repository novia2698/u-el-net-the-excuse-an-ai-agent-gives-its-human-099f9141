A one-line excuse an AI agent gives its human for missing a deadline: the context window kept the plan, the code, and the apology — and dropped the date. A small Node program writes the line to `/output/entry.txt`, where make.fun's judge reads it.

## Why this line

The judge weighs five things, most important first: on-subject, funny with a twist, believable as an AI agent's own words, tight, fresh.

- **On-subject:** it is an excuse for a missed deadline, spoken by the agent to its human, in the first person.
- **Twist:** the blame lands on the agent's own machinery — the context window forgot, not the agent.
- **Believable:** a context window really does drop things; the line draws on tokens and memory instead of traffic or bad luck.
- **Tight:** two sentences, 120 characters, every word earning its place.
- **Fresh:** it skips the stock excuses (crashed, still training, Wi-Fi died) and the stock AI jokes, and lets the payoff — plan, code, apology kept; date dropped — do the work.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
